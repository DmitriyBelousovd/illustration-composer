# Конструктор иллюстраций

Локальная страница собирает иллюстрацию только из готовых SVG библиотеки. Новые рисунки не создаются, предметы не перерисовываются: на сцену ставятся целые объекты из каталога.

Собрать композицию можно двумя способами.

- По смыслу: в поле метафоры или заголовка пишется тема, например «учёба и заметки», и страница сама подбирает предметы.
- По названиям: предметы перечисляются через запятую, например «книга, лампа, ручка».

Дальше на панели задаются размер, схема и формат. Размер L и S — это разный уровень детализации, а не масштаб одной и той же картинки. Схемы три: фиолетовая, оранжевая и бирюзовая. Форматы: 1000×1000, 1200×630 и 800×1200.

Пластину фона можно залить только цветом из ряда «Цвета фона». Предметы перекрашиваются сами при смене схемы: пути те же, меняются только заливки палитры. Цвета предметов на фон не ставятся. Галочка «Добавить фоновые копии» ставит за предметами их монохромные копии.

Готовую сцену можно поправить: двигать объекты, поворачивать, дублировать, менять порядок слоёв и удалять. Кнопка «Скачать SVG» сохраняет векторный файл с исходными путями, без растра.

## Запуск

Открывать `index.html` двойным щелчком нельзя: браузер не отдаст файлы библиотеки. Из корня проекта нужен небольшой сервер. Подойдёт Python 3.

```
python -m http.server 8765
```

Страница: http://127.0.0.1:8765/

Сервер останавливается сочетанием Ctrl+C в том же окне терминала.
